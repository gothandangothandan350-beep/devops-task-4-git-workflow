# DevOps Task 4 - Git Version Control

## Objective
Learn Git and GitHub version control best practices.

## Tools Used
- Git
- GitHub
- Windows PowerShell

## Branching Strategy
- main: stable project version
- dev: development integration branch
- feature: branch for new changes

## Tasks Completed
- Initialize a Git repository
- Create and manage branches
- Make meaningful commits
- Use pull requests to merge changes
- Configure .gitignore
- Create Git tags
- Document the workflow using Markdown
