# Git Workflow

## Branches
- main: stable release
- dev: integration of development changes
- feature/add-git-workflow-docs: new documentation work

## Workflow
1. Create a feature branch from dev.
2. Make changes and commit them.
3. Push the feature branch to GitHub.
4. Open a pull request from feature to dev.
5. Review and merge the pull request.
6. Open a pull request from dev to main.
7. Merge the reviewed changes into main.
8. Create a version tag.
